# 極座標表現（PAM）と循環成分（CPM）による非対称多次元尺度構成法

論文2本の分析コードとデータ。

- 「極座標表現に基づく非対称多次元尺度構成法の提案」（PAM）
- 「歪対称行列の循環成分に基づく非対称多次元尺度構成法の提案」（CPM）

## 概要

非対称非類似度行列 `Δ` を対称成分 `S` と歪対称成分 `A` に分解したうえで、
2通りの異なる非類似度を構成する。

### PAM（Polar Asymmetry Measure）

対称成分を第1成分、歪対称成分を第2成分とする平面上の点 `(s_ij, a_ij)` の偏角を用いる。

```
θ_ij = arctan(a_ij / s_ij)
```

`θ_ij = -θ_ji`、`θ_ii = 0` が成り立つので、絶対値 `|θ_ij|` は対称・非負・対角ゼロとなり
多次元尺度構成法の入力に使える。歪対称成分の絶対値 `|a_ij|` が不均衡の**絶対量**を
見るのに対し、偏角は対称成分で基準化した**相対量**を見る。

注意：偏角は対称成分の符号に依存するため、非類似度がすべて正となる変換が必要である。
そのため PAM では逆数変換 `δ = 100/T` を用いる（対数変換では `s_ij` が負になりうる）。

### CPM（Cyclic Pattern Measure）

歪対称成分を勾配成分と循環成分に分け、循環成分のみを用いる
（組合せ Hodge 分解、Jiang et al. 2011）。変換は対数 `δ = -log T`。

```
φ_i  = (1/n) Σ_j a_ij       各対象の全体的な傾き
G_ij = φ_i - φ_j            勾配で説明される分
C    = A - G                循環残差（行和がゼロ）
```

`C` も歪対称かつ対角ゼロなので、その列ベクトル間距離の二乗には
`A` と同じ分解が成り立つ（`i ≠ j`）。

```
d_CPM^2(i,j) = 2 * c_ij^2 + Σ_{k≠i,j} (c_ki - c_kj)^2
```

分解が歪対称性と対角ゼロのみに依存することの帰結である。

さらに、歪対称成分そのものの列ベクトル間距離との間に次の恒等式が成り立つ。

```
d_APM^2(i,j) = d_CPM^2(i,j) + n * (φ_i - φ_j)^2
```

循環成分に移ることで取り除かれるのは当該 2 対象の勾配の差だけで、第三者は関与しない。

## データ

OECD, *Foreign direct investment positions by partner country*,
OECD Data Explorer / SDMX（2026年8月19日取得）。
データフロー `OECD.DAF.INV,DSD_FDI@DF_FDI_POS_CTRY,1.0`、
**方向性原則：対外（`DO`）**・即時相手国ベース・全事業体、2023年末。

値は**10億米ドル単位・小数第1位に丸めたもの**で、論文の表1と同一である。
分析はこの丸めた値に対して行う（論文に載せる表と分析に使う値を一致させるため）。

**行が投資国、列が投資先である。** `T[i][j]` は国 i から国 j への対外直接投資ポジションで、
各セルは投資国自身の報告値である。この向きは OECD のコードリスト
（`DO` = Directional principle: outward）と実値の両方で確認した。
たとえば JPN→USA は 705.7 十億ドルで、日本の対米直接投資ポジションの公表値と一致する。

`DO` 系列は2020年から2023年まで8か国56方向すべてが欠損なく、かつすべて正の値である。
最新である2023年を採用した。2020〜2022年も同条件を満たすため頑健性の確認に使える。

## 実行

PAM（smacof が要る）

```r
install.packages(c("ggplot2", "ggrepel", "smacof"))
setwd("PAM")
source("pam_mds.R", encoding = "UTF-8")
```

CPM（smacof は不要）

```r
install.packages(c("ggplot2", "ggrepel"))
setwd("CPM")
source("cpm_mds.R", encoding = "UTF-8")
```

各スクリプトはそれぞれのフォルダ直下で実行する（`data/` への相対パスで CSV を読む）。
コードは関数にまとめず、上から下へ順に読める形で書いてある。

## 手法とMDSの対応

- PAM は古典的多次元尺度構成法では負の固有値が大きい（最小/最大 = 39.8%）ため
  SMACOF を用いる。
- CPM は `C` の列ベクトル間のユークリッド距離であり常にユークリッド距離行列となるため、
  古典的多次元尺度構成法をそのまま適用できる。

## 結果の要約（OECD FDI, 2023年, 8か国）

**PAM**：偏角の最大は JPN-BEL の 41.3 度、最小は BEL-LUX の 0.1 度。
CMDS の2次元説明率は 60.2%、SMACOF の stress-1 は 0.255。

**CPM**：歪対称成分の平方和 16.034 のうち、勾配成分が 10.096（63.0%）、
循環成分が 5.939（37.0%）。CMDS の2次元説明率は 67.7% で負の固有値なし。
直接項の寄与は 0.0%〜47.8%（平均 13.3%）。
