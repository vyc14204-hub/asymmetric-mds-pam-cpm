# 極座標表現（PAM）と循環成分（CPM）による非対称多次元尺度構成法

論文2本の分析コードとデータ。

- 「極座標表現に基づく非対称多次元尺度構成法の提案」（PAM）
- 「歪対称行列の循環成分に基づく非対称多次元尺度構成法の提案」（CPM）

## 概要

非対称非類似度行列 `D` を対称成分 `S` と歪対称成分 `A` に分解したうえで、
2通りの異なる非類似度を構成する。

### PAM（Polar Asymmetry Measure）

対称成分を実部、歪対称成分を虚部とする複素数の偏角を用いる。

```
z_ij = s_ij + i * a_ij
θ_ij = arctan(a_ij / s_ij)
```

`θ_ij = -θ_ji`、`θ_ii = 0` が成り立つので、`θ^2` は対称・非負・対角ゼロとなり
多次元尺度構成法の入力に使える。歪対称成分の絶対値 `|a_ij|` が不均衡の**絶対量**を
見るのに対し、偏角は対称成分で基準化した**相対量**を見る。

注意：偏角は非類似度の符号と原点に依存するため、`A` のみから定まる方法と違って
加法定数に不変ではない。非類似度が正となる変換（ここでは `d = 100/T`）が必要。

### CPM（Cyclic Pattern Measure）

歪対称成分を勾配成分と循環成分に分け、循環成分のみを用いる
（組合せ Hodge 分解、Jiang et al. 2011）。

```
φ_i  = (1/n) Σ_j a_ij       各対象の全体的な傾き
G_ij = φ_i - φ_j            勾配で説明される分
C    = A - G                循環残差（行和がゼロ）
```

`C` も歪対称かつ対角ゼロなので、その列ベクトル間距離には
`A` と同じ分解が成り立つ（`i ≠ j`）。

```
d_CPM^2(i,j) = 2 * c_ij^2 + Σ_{k≠i,j} (c_ki - c_kj)^2
```

分解が歪対称性と対角ゼロのみに依存することの帰結である。

## データ

OECD, *Foreign direct investment positions by partner country*,
OECD Data Explorer / SDMX（2026年8月19日取得）。
データフロー `OECD.DAF.INV,DSD_FDI@DF_FDI_POS_CTRY,1.0`、
方向性原則・即時相手国ベース・全事業体、2021年末、米ドル。

**年を2021年にした理由**：2023年は即時相手国ベースの公表がほぼ無く、8か国について
双方向がそろうペアが0組で非対称行列が構成できない。2022年は28ペアすべてそろうが
JPN→BEL が負値となり `100/T` も `-log T` も定義できない。2021年は28ペアすべて
そろい対角以外すべて正である。2020年も同条件を満たすため頑健性の確認に使える。

**未確認事項**：行と列の向き（どちらが投資元か）は OECD の系列定義で要確認。
歪対称成分の抽出・勾配循環分解・偏角の計算は向きの解釈に依存しないため、
数値結果そのものは影響を受けない。詳細は `data/` の出典ファイルを参照。

## 手法とMDSの対応

- PAM は古典的多次元尺度構成法では負の固有値が大きい（最小/最大 = 46.7%）ため
  SMACOF を用いる。
- CPM は `C` の列ベクトル間のユークリッド距離であり常にユークリッド距離行列となるため、
  古典的多次元尺度構成法をそのまま適用できる。

## 結果の要約（OECD FDI, 2021年, 8か国）

**PAM**：偏角の最大は JPN-BEL の 44.7 度、最小は KOR-LUX の 3.2 度。
CMDS の2次元説明率は 58.4%、SMACOF の stress-1 は 0.252。

**CPM**：歪対称成分の平方和 30.167 のうち、勾配成分が 15.582（51.7%）、
循環成分が 14.585（48.3%）。CMDS の2次元説明率は 76.8% で負の固有値なし。
直接項の寄与は 0.0%〜57.9%（平均 11.6%）。
